# 여의도 3D 게임 설계 (좀보이드 × 배틀로얄) — 게임성 측정용 PoC

> **이 게임 규칙은 확정이 아니다.** 여의도 월드 위에서 게임성을 재 보는 PoC이고, 나중에 전혀 다른 게임으로 바꿀 수 있다.
> 그래서 엔진(남는 것)과 게임 모드(바꿀 수 있는 것)를 코드·프로토콜에서 나눠 둔다 (아래 "엔진과 게임 모드").

결정된 값은 그대로, **(가정)** 은 아직 사용자 확인 전 임시 값이다. 단계마다 이 문서를 갱신한다.

## 엔진과 게임 모드
| | 엔진 (장르와 무관, 남는 것) | 배틀로얄 모드 (PoC, 바꿀 수 있는 것) |
|---|---|---|
| 공용 | `yeouido-sim` 월드·충돌·실내·이동, `yeouido-net` 프로토콜 | `yeouido-br` 판·전장 원·시작 자리·전투 규칙·메시지 |
| 서버 | `world.ts` 접속·입력 예산·이동·스냅숏, `mode.ts` (GameMode 인터페이스) | `modes/battle-royale.ts` |
| 클라이언트 | `GameCanvas`·카메라·다른 사람·미니맵, `modes/mode-client.ts` | `modes/br/` (경계 벽·시체·HUD·공격 버튼) |

엔진이 모드에 열어 둔 칸 (뜻은 모드가 정한다):
- 입력의 **행동 비트** 3개 (배틀로얄: 1 근접, 2 원거리)
- 사람마다 **상태 비트** 8개와 **게이지** 0~255 (배틀로얄: 죽음·무적·휘두르기·맞음, 체력). 비트 0x80 `ST_FROZEN`만 엔진 것: 입력은 받되 움직이지 않는다(클라이언트 예측도 멈춤).
- `{ t: 'mode' }` 메시지 통로 (틱마다 묶어 보냄: 모두에게 갈 것은 한 번만 직렬화)
- 서버가 welcome에서 모드 이름을 알려 주면 클라이언트가 맞는 모드 화면·HUD를 고른다

다른 게임을 만들 때: `yeouido-br`·`modes/battle-royale.ts`·`modes/br/` 를 새 모드로 바꾸고 `MODE_CLIENTS`·`MODE_HUDS`·World의 모드 생성만 고친다.

## 한 판의 흐름
- 판(게임 인스턴스) 하나 = 서버 `World` 하나. 살아 있는 판이 없을 때 참가자가 오면 새 판을 만든다. 들어오면 바로 플레이(전원 대기 없음).
- 판 길이 **20분**. 전장 원이 **10단계**로 줄어 최종 **500m** **(가정: 반경 500m)** 에 이르면 최종 보스 등장 → 처치하면 승리, 판 종료.
- 낮/밤 반복: 좀비는 **밤에만**, 해 뜨면 모두 불타 사라짐. 가끔 **뛰는 좀비**(신발 없는 사람보다 빠름). 건물 안에도 좀비.
  - **(가정)** 한 주기 5분 = 낮 3분 20초 + 밤 1분 40초 (20분에 4번)
- 플레이어끼리, 봇 플레이어끼리 서로 공격 가능.

## 시작·사망
- 맨몸으로 **무작위 위치**(지상·옥상·실내 층) 시작. 운 요소는 의도된 것.
- 사망하면 그 자리에 **시체**(가진 아이템 전부)가 남고 **다른 사람도 털 수 있다**. 무작위 위치에서 맨몸으로 다시 시작.
- 다시 시작 대기: 전장 단계 1에서 **5초**, 단계가 오를 때마다 **+5초** (10단계 50초).
- 다시 시작 직후 **무적 5초**.

## 아이템 (완성품이 떨어짐, 같은 것을 먹으면 강화)
| 칸 | 효과 | 예 |
|---|---|---|
| 도구 | 부수는 속도 | 망치 |
| 근접 | 피해·사거리 | 쇠파이프 |
| 원거리 | 피해·재장전 | 총, 활 |
| 갑옷 | 받는 피해 감소 | |
| 신발 | 이동 속도 | |
| 로켓슈트 | 비행 | |

- 같은 아이템을 먹으면 +1강, **최대 +7강**.
- 근접·원거리 **동시 사용**: 좌클릭 근접, 우클릭 원거리. 휴대폰은 화면 공격 버튼.
  - **(가정)** 3인칭의 마우스 끌기(카메라 회전)와 겹치므로 **짧게 누르면 공격, 끌면 카메라**로 구분.
- 원거리는 한 종류만: **다른 종류를 먹으면 들고 있던 것은 그 자리에 떨어진다**.
- 총알·화살 **무제한**. 1강마다 재장전 시간 감소·피해 증가.
- 비행은 로켓슈트가 있을 때만 (개발 중엔 `?debug`로 허용).

## 이동
- 기본 속도는 원래 값: 걷기 1.4m/s, 달리기 4.8m/s. 신발로 증가.
- 뛰는 좀비 **(가정)** 5.5m/s.

## 인원
- 한 판 인원 상한 없음. 봇 플레이어 **3명**.

## 실내
- 지금: KB국민은행 본점. 이름 있는 건물 **4개 추가** (섬을 지역으로 나눠 고르게).

## 2단계에서 정한 값 (가정)
- 체력 100, 맨손: 사거리 1.7m·앞쪽 좌우 60°·피해 12·대기 0.6초 (9대에 쓰러짐)
- 같은 공간만 닿는다: 실외는 높이 차 1.6m 안, 실내는 같은 건물·층 (옥상 위↔지상 아래는 안 닿음)
- 먼저 때리면 무적이 풀린다. 전장 밖 피해는 무적이어도 들어간다: 초당 2+단계 (1단계 3, 10단계 12)
- 죽으면 그 자리에 시체(이름), 내 캐릭터는 숨김 → 단계별 대기 후 원 안 무작위 자리 + 무적 5초. 시체는 판당 최근 150구
- 조작: PC 왼쪽 짧게 클릭(끌면 카메라), 휴대폰 공격 버튼(누르고 있으면 계속)

## 3단계에서 정한 값 (가정)
- 아이템 4종(근접 쇠파이프·갑옷·신발·로켓슈트), 땅에 +1로 떨어짐. 닿으면 자동으로 줍는다(1.3m, 같은 공간)
- 강화: 없던 칸이면 주운 단계, 있으면 max(지금, 주운 것)+1, 최대 +7
- 쇠파이프: 사거리 2.2m, 피해 18+4×(단계-1), 대기 700-30×(단계-1)ms / 맨손 12
- 갑옷: 근접 피해 10%+6%×(단계-1) 감소 (+7 46%), 전장 피해는 못 막음
- 신발: 땅 속도 ×(1.15+0.05×(단계-1)) → +1 달리기 5.5m/s(뛰는 좀비와 같음), +7 7.0m/s
- 로켓슈트: 비행 가능, 비행 속도 ×(0.4+0.08×(단계-1)) → +1 달려 날기 14m/s. **연료 제한 없음 — 근접만 있는 지금은 날면 못 맞힘. 밸런스는 나중에 조절 (사용자 결정)**
- 판 시작 때 500개(신발·갑옷·파이프 3 : 로켓 1, 지상 60%·옥상 30%·실내 10%), 20초마다 원 넓이만큼 유지(최소 60)
- 전장 원 밖으로 밀려난 아이템은 사라진다 (1초마다 정리)
- 죽으면 장비 전부 시체에 남고, 지나가는 사람이 전부 털어 간다
- 엔진에 더한 칸: 몸 상태의 땅·비행 속도 배율(sm·fm). 값은 모드가 정한다

## 4단계에서 정한 값 (가정)
- 부술 수 있는 물건 3종: 나무 상자(내구 30)·자판기(80)·금고(220), 판 시작 450개(상자 12 : 자판기 4 : 금고 1), 원 넓이만큼 유지(최소 50), 원 밖은 사라짐
- 근처에 닿는 사람이 없을 때 공격하면 가장 가까운 물건을 친다. 충돌 없음(지나갈 수 있음 — 엔진 충돌을 안 건드리려고)
- 부수는 힘: 망치 25+8×(단계-1), 없으면 쇠파이프 12, 맨손 8 (공격 간격은 근접 무기 그대로)
- 드롭 표: 상자 1개(꽝 3·파이프 3·갑옷 3·신발 3·망치 3·로켓 0.5, 모두 +1) / 자판기 1~2개(+1~2, 신발 많음) / 금고 2~3개(+2~3, 로켓 +1~2 확률 높음)
- 망치를 새 아이템(5번째 칸)으로 추가. 땅에 뿌리는 아이템은 50개(원 넓이만큼 유지, 최소 5), 로켓슈트는 땅에 안 뿌림 — 물건을 부숴야 나온다

## 밸런스
- 20분(500m 도달)까지 아이템을 만나 강화한 **기대 능력치**에 맞춰 보스 강도를 정한다: `보스 = 기준 × f(인원, E[전투력]) × 난이도`.
- E[전투력]은 서버 시뮬레이션만으로 봇 판을 빨리 돌려 얻고, 실제 판 기록(PostgreSQL)으로 다시 맞춘다. 난이도 쉬움·보통·어려움은 계수.

## 진행 단계
1. 판 관리 + 무작위 시작 + 전장 원 축소 + HUD, 자유 비행·임시 달리기 정리
2. 체력·사망·재시작·시체 + 맨손 근접 PvP
3. 아이템 획득·장비 칸·강화 (신발·갑옷·로켓슈트)
4. 부술 수 있는 물건 + 망치 + 드롭 표
5. 낮밤 + 좀비
6. 원거리 무기 (총 지연 보정, 활)
7. 최종 보스 + 승리 + 판 종료·재생성 + 난이도
8. 봇 플레이어 3명
9. 실내 건물 4개 추가 (4~5단계와 병행 가능)
10. 밸런스 도구 (화면 없는 판 시뮬레이션, 획득 기록)
