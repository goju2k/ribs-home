# 여의도 3D 게임 설계 (좀보이드 × 배틀로얄)

결정된 값은 그대로, **(가정)** 은 아직 사용자 확인 전 임시 값이다. 단계마다 이 문서를 갱신한다.

## 한 판의 흐름
- 판(게임 인스턴스) 하나 = 서버 `World` 하나. 살아 있는 판이 없을 때 참가자가 오면 새 판을 만든다. 들어오면 바로 플레이(전원 대기 없음).
- 판 길이 **20분**. 전장 원이 **10단계**로 줄어 최종 **500m** **(가정: 반경 500m)** 에 이르면 최종 보스 등장 → 처치하면 승리, 판 종료.
- 낮/밤 반복: 좀비는 **밤에만**, 해 뜨면 모두 불타 사라짐. 가끔 **뛰는 좀비**(신발 없는 사람보다 빠름). 건물 안에도 좀비.
  - **(가정)** 한 주기 5분 = 낮 3분 20초 + 밤 1분 40초 (20분에 4번)
- 플레이어끼리, 봇 플레이어끼리 서로 공격 가능.

## 시작·사망
- 맨몸으로 **무작위 위치**(지상·옥상·실내 층) 시작. 운 요소는 의도된 것.
- 사망하면 그 자리에 **시체**(가진 아이템 전부)가 남고 **다른 사람도 털 수 있다**. 무작위 위치에서 맨몸으로 다시 시작.
- 다시 시작 대기: 전장 단계 1에서 **5초**, 단계가 오를 때마다 **+5초** (10단계 50초).
- 다시 시작 직후 **무적 5초**.

## 아이템 (완성품이 떨어짐, 같은 것을 먹으면 강화)
| 칸 | 효과 | 예 |
|---|---|---|
| 도구 | 부수는 속도 | 망치 |
| 근접 | 피해·사거리 | 쇠파이프 |
| 원거리 | 피해·재장전 | 총, 활 |
| 갑옷 | 받는 피해 감소 | |
| 신발 | 이동 속도 | |
| 로켓슈트 | 비행 | |

- 같은 아이템을 먹으면 +1강, **최대 +7강**.
- 근접·원거리 **동시 사용**: 좌클릭 근접, 우클릭 원거리. 휴대폰은 화면 공격 버튼.
  - **(가정)** 3인칭의 마우스 끌기(카메라 회전)와 겹치므로 **짧게 누르면 공격, 끌면 카메라**로 구분.
- 원거리는 한 종류만: **다른 종류를 먹으면 들고 있던 것은 그 자리에 떨어진다**.
- 총알·화살 **무제한**. 1강마다 재장전 시간 감소·피해 증가.
- 비행은 로켓슈트가 있을 때만 (개발 중엔 `?debug`로 허용).

## 이동
- 기본 속도는 원래 값: 걷기 1.4m/s, 달리기 4.8m/s. 신발로 증가.
- 뛰는 좀비 **(가정)** 5.5m/s.

## 인원
- 한 판 인원 상한 없음. 봇 플레이어 **3명**.

## 실내

## 밸런스
- 20분(500m 도달)까지 아이템을 만나 강화한 **기대 능력치**에 맞춰 보스 강도를 정한다: `보스 = 기준 × f(인원, E[전투력]) × 난이도`.
- E[전투력]은 서버 시뮬레이션만으로 봇 판을 빨리 돌려 얻고, 실제 판 기록(PostgreSQL)으로 다시 맞춘다. 난이도 쉬움·보통·어려움은 계수.

## 진행 단계
1. 판 관리 + 무작위 시작 + 전장 원 축소 + HUD, 자유 비행·임시 달리기 정리
2. 체력·사망·재시작·시체 + 맨손 근접 PvP
3. 아이템 획득·장비 칸·강화 (신발·갑옷·로켓슈트)
4. 부술 수 있는 물건 + 망치 + 드롭 표
5. 낮밤 + 좀비
6. 원거리 무기 (총 지연 보정, 활)
7. 최종 보스 + 승리 + 판 종료·재생성 + 난이도
8. 봇 플레이어 3명
9. 실내 건물 4개 추가 (4~5단계와 병행 가능)
10. 밸런스 도구 (화면 없는 판 시뮬레이션, 획득 기록)
